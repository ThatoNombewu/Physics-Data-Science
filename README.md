## 🌌 Astrophysics

### H I 21-cm Galactic Rotation — Measuring the Rotation of the Milky Way

- **Role:** Researcher / Author
- **Timeline:** Undergraduate research project
- **Summary:** Analysed H I 21-cm radio observations to investigate the rotational motion of the Milky Way. Observations were performed using the Tony Fairall Teaching Telescope, with spectral analysis used to determine Doppler velocities and investigate Galactic rotation at different Galactic longitudes.
- **Tech Stack:** Python, NumPy, SciPy, Matplotlib, Jupyter
- **Key Methods:** Radio spectroscopy, spectral-line analysis, Doppler velocity calculations, uncertainty analysis, data visualization
- **Reproducibility:** Analysis notebooks and supporting data will be provided in the project directory where permitted.
- **Status:** Completed

### GW190521 — Gravitational-Wave Echoes and Stimulated Hawking Radiation

- **Role:** Researcher
- **Timeline:** Undergraduate research
- **Summary:** Investigated the possibility of detecting gravitational-wave echoes associated with stimulated Hawking radiation from black holes. The project examined the theoretical motivation for echoes and their potential observational signatures in gravitational-wave data.
- **Tech Stack:** Python, scientific computing, astronomical data-analysis tools
- **Topics:** Black holes, Hawking radiation, gravitational waves, GW190521, gravitational-wave echoes
- **Status:** Research project

## ⚛️ Particle Physics

### Constituent Quark Model — Modelling Hadron Masses

- **Role:** Researcher / Author
- **Timeline:** Undergraduate final-year project
- **Summary:** Investigated hadron masses using the Constituent Quark Model (CQM), exploring how constituent quark properties and interactions can be used to model experimentally observed hadron masses. The project also examined problems surrounding the mass of the η′ meson and its connection to Quantum Chromodynamics.
- **Tech Stack:** Python, numerical methods, scientific computing
- **Topics:** QCD, Constituent Quark Model, hadron spectroscopy, mesons, baryons, quark masses, η′ mass puzzle
- **Status:** Completed

## 🧪 Experimental Physics

### Gamma-Ray Spectroscopy — Neutron Activation of Aluminium

- **Role:** Researcher / Analyst
- **Timeline:** Undergraduate laboratory project
- **Summary:** Analysed gamma-ray spectroscopy data obtained from neutron activation of aluminium. The project involved processing detector data, identifying radioactive decay signals, fitting decay curves, and determining the half-life associated with the produced radioactive isotope ²⁸Al.
- **Tech Stack:** Python, NumPy, SciPy, Matplotlib, Jupyter
- **Key Methods:** Gamma spectroscopy, radioactive decay analysis, curve fitting, signal processing, uncertainty analysis
- **Data:** TSV experimental datasets
- **Status:** Completed
